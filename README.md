# Ranveer Jaiswal - Portfolio

A modern, interactive 3D portfolio website built with React, Three.js, and advanced animations.

## 🌟 Features

- **3D Graphics**: Interactive Three.js animations and 3D elements
- **Custom Cursor**: Dynamic cursor with different states for hover interactions
- **Smooth Scrolling**: Implemented with Lenis for buttery-smooth scroll experience
- **Responsive Design**: Fully responsive across all devices
- **Modern UI**: Glass morphism effects and gradient designs
- **Multiple Sections**:
  - Hero with 3D elements
  - About section with animations
  - Skills showcase (MERN Stack & AI Automation)
  - Projects gallery
  - Contact form
  - Separate page for additional skills

## 🛠️ Technologies Used

- **Frontend**: React 18, React Router DOM
- **3D Graphics**: Three.js, React Three Fiber, React Three Drei
- **Animations**: Framer Motion, GSAP
- **Smooth Scroll**: Lenis
- **Build Tool**: Vite
- **Styling**: Custom CSS with CSS Variables

## 📦 Installation

1. Clone the repository:
```bash
git clone <repository-url>
cd Portfolio
```

2. Install dependencies:
```bash
npm install
```

3. Run the development server:
```bash
npm run dev
```

4. Build for production:
```bash
npm run build
```

5. Preview production build:
```bash
npm run preview
```

## 🚀 Usage

The portfolio consists of:

- **Home Page**: Contains all main sections (Hero, About, Skills, Projects, Contact)
- **Additional Skills Page**: Detailed breakdown of all technical and soft skills

Navigate using the navbar or scroll through sections on the home page.

## 🎨 Customization

### Colors
Edit the CSS variables in `src/index.css`:
```css
:root {
  --primary: #6366f1;
  --secondary: #8b5cf6;
  --accent: #ec4899;
  --dark: #0f172a;
  --light: #f8fafc;
  --gray: #64748b;
}
```

### Content
- Update personal information in component files
- Modify skills, projects, and experience data in respective component files
- Add your own social media links in the Contact section
